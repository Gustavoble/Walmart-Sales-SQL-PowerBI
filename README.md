# Walmart-Sales-SQL-PowerBI
End-to-End Walmart Sales Data Analysis using MySQL and Power BI


Walmart Sales Data Analysis | SQL + Power BI
📊 Project Overview

This project is an end-to-end Walmart Sales Data Analysis project developed using MySQL and Power BI.

The project analyses Walmart sales transaction data to uncover insights into:

💰 Sales revenue and gross income
🏪 Branch performance
🛍️ Product performance
👥 Customer behaviour
💳 Payment methods
⭐ Customer ratings
⏰ Sales patterns and peak sales hours

The data was analysed using MySQL Workbench and visualized using Power BI to create interactive dashboards for business decision-making.

🎯 Business Problem

Businesses need to understand their sales performance to make informed decisions.

This project aims to answer important business questions such as:

Which branch generates the highest revenue?
Which product lines perform best?
Which customer groups generate the most revenue?
Which payment methods are most popular?
When do the highest sales occur?
Which products generate the highest gross income?
How do customer ratings vary?
What business areas could be improved?

The goal is to transform raw sales transaction data into meaningful and actionable business insights.

💡 Business Recommendations
1. Focus on High-Performing Products

Increase stock availability and marketing efforts for product lines generating high revenue and gross income.

2. Improve Low-Performing Products

Investigate weaker product categories to identify possible issues related to pricing, demand, availability, or promotion.

3. Learn From High-Performing Branches

Analyse successful strategies used by the best-performing branches and apply relevant practices to other locations.

4. Improve Customer Satisfaction

Focus on product categories and customer groups with lower average ratings.

5. Optimise Operations During Peak Hours

Use sales-by-hour analysis to ensure appropriate staffing and stock availability during busy periods.

6. Support Popular Payment Methods

Ensure frequently used payment options remain reliable and convenient for customers.
